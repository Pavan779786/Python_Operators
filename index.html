Python Operators, explained one symbol at a time

An operator is just a small symbol that tells Python to do something with values — add them, compare them, combine conditions, or check what's inside something. That's it. No prior programming knowledge needed — we'll build up from what a "value" even is.

Think of an operator the way you'd think of a math symbol like + or = on a calculator. In Python, the "numbers" on either side of an operator are called operands. So in 5 + 3, the operands are 5 and 3, and + is the operator. Python groups its operators into seven families, based on what job they do. We'll go through each family below — every operator gets a plain-English explanation, a runnable example, and its real output.
